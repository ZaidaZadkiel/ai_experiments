Last discussion: what M3 (symbol-scope) shows, open question MVP-4.

The [Decided] M3 example says a variable is shown "as belonging to that function's
scope, together with the symbols it is used with". The question was who shows the
second half: M3 itself, the Viewer, or nobody yet.

Options weighed:
  A  lexical scope only, no uses
  B  M3 also reads references and outputs scope-to-symbol uses
  C  lexical scope in M3; the Viewer lifts existing reference and link edges up to scopes
  D  nested and block scopes (needs M1 changes)

Decided: C with C1. M3 reads symbols only and records the file scope plus one scope
per top-level function; each scope names its owner (the function symbol, or the file).
The Viewer lifts every edge to the nearest visible container, starting from the scope
its source owns, so a scope shows the symbols it is used with. D is kept for after the
MVP (MVP_scope.md, section 10.3).
Recorded in: MVP_scope.md (MVP-4), mvp_docs/04_tools.md (TOOL-33),
mvp_docs/05_viewer.md (VIEW-13), mvp_docs/99_findings.md (FND-55).
